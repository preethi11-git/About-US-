# About Us – Educational Technology Platform

A modern, responsive About Us webpage designed for an educational technology platform focused on helping BE/BTech students bridge the gap between academic learning and industry requirements.

## 🌟 Project Overview

This webpage communicates the platform's vision, mission, learning approach, and commitment to preparing students for real-world technology careers.

The design follows a clean, modern, editorial-inspired visual style with a warm and minimal colour palette.

## 🎨 Design Theme

- **Background:** Warm Ivory – `#F7F5EF`
- **Primary Text:** Charcoal – `#242722`
- **Primary Accent:** Sage Green – `#55745F`
- **Secondary Accent:** Terracotta – `#B87558`

### Typography
- Manrope – Headings
- Inter – Body text
- IBM Plex Mono – Technical labels

## ✨ Key Features

- Modern and responsive About Us layout
- Clear presentation of the platform's mission and vision
- Student-focused content and learning approach
- Visually engaging sections and imagery
- Clean typography and consistent colour palette
- Responsive experience across desktop, tablet and mobile

## 🚀 Deployment on Vercel

This project can be deployed using Vercel.

1. Push the project to GitHub.
2. Visit [Vercel](https://vercel.com/).
3. Sign in using your GitHub account.
4. Select **Add New → Project**.
5. Import the `About-US-` repository.
6. Configure the project settings according to your framework and project structure.
7. Click **Deploy**.
8. Once deployment is complete, Vercel will provide a live URL.

For a plain HTML/CSS/JavaScript project, select **Other** as the framework preset and use the correct directory containing your `index.html` file as the root directory.
