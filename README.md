# TechZentra – About Us Website

A modern, responsive About Us webpage for **TechZentra**, designed to introduce the organization, highlight its leadership, communicate its vision, and showcase its learning-focused environment.

🌐 **Live Website:** https://about-us-ecru-gamma.vercel.app  
📂 **GitHub Repository:** https://github.com/preethi11-git/About-US-

---

## 📌 Project Overview

The TechZentra About Us website is designed to provide visitors with a clear understanding of the organization, its vision, leadership, and commitment to technology-driven education.

The webpage presents the organization's identity through a clean, modern, and user-friendly interface. It aims to build trust, communicate its values, and give students and visitors an overview of the learning environment.

The design focuses on visual storytelling, structured content, responsive layouts, and an accessible browsing experience.

## 🎯 Project Objectives

- Establish a professional online identity for TechZentra.
- Introduce the organization's background, mission, and vision.
- Highlight the founder and leadership.
- Present the organization's learning environment through relevant imagery.
- Create an engaging and easy-to-navigate user experience.
- Ensure the webpage works across desktop, tablet, and mobile devices.

## ✨ Key Features

### 1. About TechZentra
Introduces the organization, its purpose, and its approach to technology-focused education.

### 2. Mission and Vision
Communicates the organization's goals, values, and long-term direction.

### 3. Founder Profile
Features the founder's profile, professional background, expertise, and vision.

### 4. Stories Worth Sharing
Uses relevant photographs featuring Indian students and technology learners to create a more relatable visual experience.

### 5. Modern User Interface
- Clean and structured layouts.
- Consistent typography and colour palette.
- Organized content sections.
- Responsive image presentation.
- Subtle visual interactions.

### 6. Responsive Design
Designed to provide a consistent browsing experience on desktops, tablets, and mobile devices.

## 🚀 Getting Started

Follow these steps to run the project on your local machine.

### Prerequisites

- A computer with Windows, macOS, or Linux.
- A modern web browser.
- Visual Studio Code (recommended).
- Git (optional, for cloning the repository).

### Step 1: Clone the Repository

Open your terminal and execute:

```bash
git clone https://github.com/preethi11-git/About-US-.git
```

### Step 2: Open the Project Folder

```bash
cd About-US-
```

### Step 3: Open in Visual Studio Code

```bash
code .
```

Alternatively, open the downloaded project folder directly in Visual Studio Code.

### Step 4: Run the Website

Open `index.html` in your browser.

For a better development experience, you can use the **Live Server** extension in Visual Studio Code.

Right-click `index.html` and select **Open with Live Server**.

The website will open in your default browser.
